# scosu

The game client of [scosu](https://scosu.net): a free rhythm game server with its own rankings, leaderboards, daily
tasks and community.

## Playing

Download the latest release from [scosu.net](https://scosu.net), log in or register from the game, and play.

Questions, bug reports and server status: join the [Discord](https://discord.gg/zXvV8Mm8JY).
